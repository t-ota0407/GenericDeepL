# GenericDeepL 使い方ガイド

クリップボードにコピーした文章を、ワンアクションで自動翻訳できる Windows 常駐ツールです。
`Ctrl + C` をすばやく **2 回** 押すだけで、コピーした文章を日本語あるいは英語に翻訳して表示します。

---

## 1. 動作環境

- **OS**: Windows 10 / 11（64bit）
- **必要なランタイム**: [.NET 6 デスクトップランタイム（Desktop Runtime x64）](https://dotnet.microsoft.com/download/dotnet/6.0)
  - 起動時に「.NET ランタイムが見つかりません」と表示された場合は、上記ページから
    **「.NET Desktop Runtime 6.0.x」** の x64 をインストールしてください。
- **インターネット接続**: 翻訳は Google のクラウド API を使うため、オンラインである必要があります。
- **Google Vertex AI の API キー**: 翻訳には API キーが必要です（取得方法は「4. 初期設定」を参照）。

---

## 2. 導入手順

1. **`GenericDeepL.msi`** をダブルクリックします。
2. 「Windows によって PC が保護されました」（SmartScreen）が表示された場合は、
   **「詳細情報」→「実行」** の順にクリックしてください。
   （このアプリはコード署名を行っていないため、未署名の警告が出ますが動作に問題はありません）
3. 画面の指示に従ってインストールを完了します。
4. インストール後、スタートメニューまたはデスクトップから **GenericDeepL** を起動します。

> 💡 起動するとウィンドウが開き、同時に **画面右下の通知領域（システムトレイ）** に
> アイコンが常駐します。ウィンドウを閉じてもアプリは終了せず、トレイに残り続けます。

---

## 3. 初回起動時のセットアップ

1. アプリを起動し、画面右上の **「⚙ 設定」** をクリックします。
2. **「Google Vertex AI API キー」** 欄に、自分の API キーを貼り付けます。
3. **「保存」** を押します。

これで翻訳が使えるようになります。リージョンやモデルは初期値のままで問題ありません。

---

## 4. API キーの取得について

このアプリは Google の **Vertex AI（Gemini モデル）** を使って翻訳します。利用には
**自分の Google Cloud の API キー** が必要です（アプリには API キーは含まれていません）。

おおまかな取得手順は次のとおりです。

1. [Google Cloud Console](https://console.cloud.google.com/) にログインし、プロジェクトを作成（または選択）します。
2. **Vertex AI API** を有効化します。
3. 「API とサービス」→「認証情報」から **API キー** を作成します。
4. 作成した API キーをコピーし、本アプリの設定画面に貼り付けます。

> ⚠️ **課金について**: Vertex AI の利用には Google Cloud 側で料金が発生する場合があります。
> 料金体系や無料枠は Google の公式情報をご確認ください。

## 5. 基本的な使い方

### クリップボード翻訳（メイン機能）

1. 翻訳したい文章を選択して **`Ctrl + C`** でコピーします。
2. 続けてもう一度 **`Ctrl + C`**（合計 2 回をすばやく）押します。
3. ウィンドウが自動的に開き、コピーした文章とその翻訳が表示されます。

> 日本語↔英語は **自動判定** されます（日本語をコピーすれば英語へ、英語をコピーすれば日本語へ）。

### 手動で翻訳する

ウィンドウ左側の入力欄に文章を貼り付け・入力し、**「翻訳する」** ボタンを押しても翻訳できます。

### 翻訳先の言語を固定する

ウィンドウ下部の **「翻訳先」** で、`自動` / `英語` / `日本語` を選べます。
特定の言語へ必ず翻訳したいときに使います。

## 6. ウィンドウの操作

| 操作 | 動作 |
|---|---|
| 上部バーをドラッグ | ウィンドウを移動 |
| 上部バーを **ダブルクリック** | 最大化 ⇔ 元のサイズ を切り替え |
| **「最小化」** ボタン | タスクバーへ最小化（アニメーション付き） |
| **「終了」** ボタン | アプリを完全に終了（トレイからも消えます） |
| ウィンドウ右上の閉じる操作 | ウィンドウを隠すだけ（アプリはトレイに常駐し続けます） |
| 端をドラッグ | ウィンドウサイズを変更 |

### トレイアイコンの操作

画面右下のトレイアイコンを **右クリック** すると、次のメニューが使えます。

- **Show Window** … ウィンドウを表示
- **Settings** … 設定画面を開く
- **Exit** … アプリを終了

トレイアイコンを **ダブルクリック** してもウィンドウを表示できます。

## 7. 設定項目

設定画面（右上の「⚙ 設定」）では以下を変更できます。

| 項目 | 説明 |
|---|---|
| **Google Vertex AI API キー** | 翻訳に使う API キー。必須。 |
| **リージョン** | API を呼び出すリージョン。通常は初期値（`global`）のままで OK。 |
| **モデル** | 使用する Gemini モデル。速度重視なら `*-flash-lite` 系がおすすめ。 |
| **翻訳スタイル** | `標準` / `カジュアル` / `フォーマル` / `厳密な直訳` / `自然さを優先した翻訳` から選択。 |
| **Windows 起動時に自動実行** | オンにすると、PC 起動時に自動でトレイ常駐します。 |

変更後は必ず **「保存」** を押してください。

---

## 8. アンインストール

Windows の **「設定」→「アプリ」→「インストールされているアプリ」** から
**GenericDeepL** を選んでアンインストールできます。
（または、もう一度 MSI を実行して「削除」を選択）

## 9. 困ったときは（トラブルシューティング）

| 症状 | 対処 |
|---|---|
| 起動時に「.NET ランタイムが見つかりません」と出る | [.NET 6 デスクトップランタイム](https://dotnet.microsoft.com/download/dotnet/6.0)（x64）をインストール |
| `Ctrl + C` 2 回で反応しない | 2 回を **1 秒以内** にすばやく押してください。アプリ（トレイアイコン）が起動しているかも確認 |
| 「API キーが設定されていません」と表示される | 設定画面で API キーを入力して保存してください |
| 「APIエラー」「モデルが利用できません」と表示される | API キーが正しいか、リージオン／モデルの組み合わせが有効かを設定画面で確認してください |
| 翻訳されない・タイムアウトする | インターネット接続と API キーの有効性を確認してください |
| ウィンドウを閉じてもアプリが残る | 仕様です。完全に終了するには「終了」ボタンかトレイメニューの「Exit」を使ってください |

## 10. プライバシーと注意事項

- **翻訳するテキストは Google の Vertex AI（クラウド）へ送信されます。** 機密情報の取り扱いにはご注意ください。ただし、Vertex AIは送信されたデータを学習しないようにできます。
- **API キーはこの PC 内に暗号化（Windows DPAPI）して保存** されます。設定ファイルに平文で残ることはなく、他の PC へコピーしても復号できません。
- API キーの利用料金は、キーを発行した Google Cloud アカウントに請求されます。第三者にキーが流出しないように気を付けてください。
